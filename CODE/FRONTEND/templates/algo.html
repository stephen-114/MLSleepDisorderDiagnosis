About These Algorithms

Support Vector Machine

Type: Discriminative Classifier
Kernel: RBF (Radial Basis Function)
Best For: High-dimensional data, clear margin separation

SVM works by finding the hyperplane that best separates different classes. It's particularly effective when there's a clear margin of separation and can handle non-linear classification using kernel tricks.

Random Forest

Type: Ensemble Method
Estimators: 100 Decision Trees
Best For: Robust predictions, feature importance

Random Forest creates multiple decision trees and merges their predictions. It reduces overfitting and provides excellent accuracy by averaging multiple tree outputs. Great for understanding feature importance.

XGBoost

Type: Gradient Boosting
Method: Sequential Ensemble
Best For: High performance, speed, accuracy

XGBoost uses gradient boosting framework that builds trees sequentially, where each new tree corrects errors from previous ones. Known for winning ML competitions with superior performance and speed.

Understanding the Metrics

Definition: The ratio of correctly predicted observations to total observations.
Formula: (TP + TN) / (TP + TN + FP + FN)
Range: 0 to 1 (0% to 100%)
Best When: Classes are balanced and all types of errors are equally important.

Definition: The ratio of correctly predicted positive observations to total predicted positives.
Formula: TP / (TP + FP)
Range: 0 to 1 (0% to 100%)
Best When: The cost of false positives is high (e.g., spam detection).

Definition: The ratio of correctly predicted positive observations to all actual positives.
Formula: TP / (TP + FN)
Range: 0 to 1 (0% to 100%)
Best When: The cost of false negatives is high (e.g., disease detection).

Definition: The harmonic mean of Precision and Recall.
Formula: 2 × (Precision × Recall) / (Precision + Recall)
Range: 0 to 1 (0% to 100%)
Best When: You need a balance between Precision and Recall, especially with imbalanced classes.
