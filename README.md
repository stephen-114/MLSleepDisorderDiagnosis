# 🧠 Sleep Disorder Diagnosis using Machine Learning

## 📌 Overview

This project focuses on predicting sleep disorders using machine learning techniques based on physiological and clinical data.
It includes data preprocessing, feature selection, model training, and prediction.

---

## 🚀 Key Features

* Data preprocessing and cleaning
* Feature selection for improved accuracy
* Machine learning model training
* Prediction of sleep disorders
* Backend integration using Flask

---

## 🛠 Tech Stack

* **Programming Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn
* **Backend:** Flask
* **Tools:** Jupyter Notebook, Git

## ⚙️ How to Run the Project

### 1️⃣ Clone the repository

```bash
git clone https://github.com/stephen-114/MLSleepDisorderDiagnosis.git
cd MLSleepDisorderDiagnosis
```

### 2️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Download dataset

* Download from the link above
* Place it inside:
  CODE/BACKEND/

### 4️⃣ Run the project

* Open Jupyter Notebook OR
* Run Flask backend
